# IPL Data Analysis Dashboard

## Project Overview

This project is an **IPL Data Analysis Dashboard** created using **Microsoft Excel** to analyze Indian Premier League match data and present meaningful insights through interactive visualizations.

The dashboard focuses on understanding team performance, match outcomes, scoring patterns, and other important trends across IPL matches.

The goal of this project was to transform raw IPL data into a clear and easy-to-understand dashboard that can support data-driven analysis.

---

## Objectives

* Analyze IPL match data using Excel
* Understand team-wise performance
* Identify match-winning patterns
* Analyze runs and scoring trends
* Compare team performances
* Create meaningful KPIs and visualizations
* Practice data cleaning, analysis, and dashboard development

## Key Business Questions

The dashboard was designed to answer questions such as:

* Which teams have performed better over the matches analyzed?
* Which teams have won the most matches?
* How are matches distributed across different outcomes?
* What scoring patterns can be observed?
* Which teams show stronger overall performance?
* How does match performance vary across seasons or other available dimensions?
* What insights can be derived from historical IPL match data?

## Data Analysis Process

The project followed a structured data analysis workflow:

### 1. Data Collection

Used IPL match data containing information related to teams, matches, outcomes, and other relevant attributes.

### 2. Data Cleaning

* Checked for missing values
* Reviewed inconsistent entries
* Standardized relevant fields
* Prepared the dataset for analysis

### 3. Data Transformation

Used Excel formulas and calculated fields where required to prepare the data for analysis.

### 4. Data Analysis

Created Pivot Tables to identify:

* Team performance
* Match outcomes
* Winning patterns
* Scoring trends
* Other relevant IPL statistics

### 5. Data Visualization

Converted the analyzed data into charts and dashboard components to make the insights easier to understand.

### 6. Dashboard Creation

Combined KPIs, charts, tables, and slicers into a single interactive Excel dashboard.
